## Usage notes

- Use the styled [|<]ompendium wordmark for brand-forward placements.
- Use plain Kompendium or Kompendium, LLC in legal and body-copy contexts.
- Use the bracket-pipe-angle mark as the compact icon, avatar, or favicon.
- Keep clear space around the mark equal to the width of the vertical pipe.
- Do not replace the [|<] mark with a normal K in the primary logo artwork.
